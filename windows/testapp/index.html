Measurement limits: these are local, automated pixel-processing bots, not an LLM-driven bot; no AI model tokens are generated or measured. The screenshot timing includes asynchronous PNG encoding/decoding and pixel scanning, so it is path wall time—not CPU time or hardware watts. The Perch path simulates the Windows eye's 16×10 changed-cell format on generated frames; it does not read the installed driver's live feed. Results compare this repeatable vision task, not total real-agent CPU, power, or token costs.

The benchmark runs only in this browser on localhost. Encoded screenshots are analyzed locally and discarded after their byte count is recorded. No screenshots are uploaded or retained.
